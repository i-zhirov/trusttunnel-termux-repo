TrustTunnel for Termux

Prebuilt packages for the TrustTunnel endpoint and command-line client.

Packages

    __VERSIONS__

Setup

pkg install -y curl gnupg
curl -fsSL __KEY_URL__ \
  -o "$PREFIX/etc/apt/trusted.gpg.d/trusttunnel.gpg"
echo "deb [signed-by=$PREFIX/etc/apt/trusted.gpg.d/trusttunnel.gpg] __REPO_URL__ termux extras" \
  > "$PREFIX/etc/apt/sources.list.d/trusttunnel.list"
pkg update

Install

pkg install -y trusttunnel-client
pkg install -y trusttunnel
